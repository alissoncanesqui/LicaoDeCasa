# Altar Server Scheduler

Quero construir um app on line para criação da escala de coroinhas da igreja. O app precisa ter uma página de missas onde cada pai entra na data e horário e seleciona seus filhos numa lista já cadastrada. Numa outra página quero que tenha uma página de minhas inscrições onde será possível ver quais missas meus filhos estão escalados .  O app também precisa ter uma página de coordenadores com acesso de senha. Nessa parte precisa ter 4 telas.. Uma tela de cadastro de missas, uma tela de cadastro de coroinhas, uma tela de controle de assiduidade dos coroinhas onde o coordenador coloca se ele estava presente ou não e uma tela onde é possível ver a escala completa de um determinado período e pode exportar para o Excel.
